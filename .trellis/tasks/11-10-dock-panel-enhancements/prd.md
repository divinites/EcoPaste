# 底部停靠面板增强：实时重排、滑入滑出、拖拽调高、显示器策略、快捷序号

## Goal

在已上线的 Paste 风格底部停靠面板（`clipboard.window.layout = dock`）上补齐五项体验，
让面板的几何响应、出现方式和快捷粘贴提示更接近 Paste，同时不改变 `vertical` 布局的任何行为。

## Requirements

### R1 改设置后立即重排窗口

- 剪贴板窗口可见时，修改 `layout`、`dockHeightPercent` 或 `dockMonitor`，窗口几何立即按新值应用，不必等下一次呼出。
- 窗口不可见时行为不变（下次呼出时应用）。
- 可见状态下的重排留在窗口当前所在显示器，不因光标在别的屏（例如偏好设置窗口所在屏）而跳屏。

### R2 滑入 / 滑出动画

- dock 布局下，面板呼出时从屏幕底边向上滑入，隐藏时向下滑出。
- 粘贴触发的隐藏不播放滑出，立即隐藏，粘贴延迟不得增加。
- 系统开启“减弱动态效果”时不播放动画。
- 滑出期间再次呼出，面板必须正常显示，不得出现“已呼出却被延迟隐藏收走”。
- `vertical` 布局不加动画。

### R3 拖拽上边缘调整高度

- dock 面板上边缘有可拖拽区域，光标为上下调整样式；拖动时面板高度实时跟随，底边始终贴工作区底部。
- 高度受现有范围约束：25%–60% 工作区高度，且不低于 280 逻辑像素。
- 松手后把结果换算为整数百分比写入 `clipboard.window.dockHeightPercent`，偏好设置里的数值同步更新。
- 拖拽开始时关闭悬浮预览；拖拽过程中面板不得因失焦逻辑被隐藏。

### R4 显示器选择策略

- 新增设置 `clipboard.window.dockMonitor`，选项：
  - `cursor`：光标所在显示器（默认，等同现状）；
  - `activeWindow`：当前前台应用窗口所在显示器；
  - `primary`：主显示器。
- 仅 dock 布局生效；`vertical` 布局下该项禁用。
- 策略解析失败（取不到前台窗口、取不到主屏）时回落到光标所在显示器。
- 旧配置文件无此字段时取默认值，不需要迁移。

### R5 dock 卡片常显快捷粘贴序号

- dock 布局下，可快捷粘贴的卡片（现有 `hintKey` 覆盖的前若干张可见卡片）在卡片上常显序号徽标，
  不需要先按住修饰键才看得到。
- 按住修饰键时现有的 `KeyHint` 行为不变；快捷粘贴的按键与范围不变。
- 鼠标悬停卡片时，快捷动作按钮优先显示，序号徽标让位。

## Constraints

- Rust-First：几何计算、显示器解析、设置校验与持久化都在 Rust；前端只发指针位置和渲染动画。
- 仅 macOS + Windows；两端同步实现，无法在本机验证的 Windows 路径需在交付说明里明确标注。
- 不改已定决策：`layout` 默认 `dock`、高度为百分比（25–60，默认 40）、`vertical` 卡片样式不动。
- 新设置项必须同步 Rust 模型、TS 类型、`src/constants/`、`preferenceSchema`、zh-CN / en-US 文案。
- 新命令名、事件名集中维护在 Rust 模块常量和 `src/constants/`。

## Out of Scope

- 类型配色自定义、多选与批量操作。
- `vertical` 布局的动画或拖拽行为变更。
- 动画时长、缓动的用户可配置项。
- `char_count` 对组合 emoji 的计数口径调整。

## Acceptance Criteria

- [ ] AC1：固定（不自动隐藏）剪贴板窗口后，在偏好设置把高度从 40 改为 55，面板立即变高且仍贴底，未跳到其它显示器。
- [ ] AC2：面板可见时把布局从 `dock` 切到 `vertical`，窗口立即变回竖向小窗尺寸；再切回 `dock` 立即整宽贴底。
- [ ] AC3：快捷键呼出时面板自底部滑入；按 Esc 或点击外部时向下滑出后隐藏。
- [ ] AC4：双击卡片粘贴时面板立即消失，无滑出，内容正确粘贴到前台应用。
- [ ] AC5：滑出过程中再次按呼出快捷键，面板保持显示且可操作。
- [ ] AC6：系统“减弱动态效果”开启时，呼出与隐藏均无位移动画。
- [ ] AC7：拖动面板上边缘可实时调高调低，超出 25%–60% 时停在边界；松手后偏好设置中的百分比等于新高度对应值，下次呼出保持该高度。
- [ ] AC8：`dockMonitor = primary` 时，光标在副屏呼出，面板出现在主屏；`activeWindow` 时出现在前台窗口所在屏；`cursor` 行为与改动前一致。
- [ ] AC9：删除配置文件中的 `dockMonitor` 字段后启动，应用正常，取值为 `cursor`。
- [ ] AC10：dock 卡片不按修饰键即可看到序号徽标；按 ⌘/Ctrl + 对应数字粘贴的条目与徽标一致；悬停时显示快捷动作按钮。
- [ ] AC11：`vertical` 布局下呼出、隐藏、卡片外观与改动前一致。
- [ ] AC12：`cargo fmt --check`、`cargo clippy -- -D warnings`、`cargo test`、`pnpm lint` 全部通过。
